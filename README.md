# Ruta de Bares 🍻

App móvil (React Native + Expo) para planear y compartir rutas de bares.

## Stack

- [Expo](https://expo.dev/) + React Native
- TypeScript

## Empezar

```bash
npm install
npm start
```

Luego escanea el QR con la app **Expo Go** (Android/iOS), o usa:

```bash
npm run android
npm run ios
npm run web
```
